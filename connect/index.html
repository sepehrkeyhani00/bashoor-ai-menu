Public MCP endpoint: https://bashoor.ir/mcp. Transport: Streamable HTTP. Authentication: none. Four read-only tools: get_visit_guide, get_business_profile, get_menu, search_menu.

OpenAI publication draft

Download the plugin ZIP. It contains a remote MCP configuration, icon, bilingual listing and five positive / three negative review cases. It is a publication draft, not evidence of OpenAI approval. The publisher must complete developer-identity and domain verification, provide a reviewer-accessible demonstration recording and resolve dashboard validation before submission. Category and publisher display name must match the dashboard.

Gemini API

Remote MCP tool configuration for an application using Gemini’s Interactions API. This developer configuration does not install Bashoor in every consumer Gemini account.

Discovery

The MCP registry listing allows compatible clients to discover the connection. Each client chooses which connections to enable and when to call them. Publishing an MCP does not guarantee recommendations or search placement. The same public facts are available in the visit guide and live menu snapshot.
